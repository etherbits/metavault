EZQ syntax

EZQ is the query language used on Metavault’s Query page. It can search, create, update, and delete library entries.

On this page Syntax Actions Qualifiers Commands Examples

Basic syntax

/action expression #command

The action says what to do. The expression selects entries or gives values to write. Commands are optional. They run after the action and never change which entries an update or delete targets.

Expression operators

space

AND

Both conditions must match. status:finished tag:drama

|

OR

Either condition may match. media_type:movie | media_type:anime

!

NOT

Excludes a condition. !adult:true excludes adult entries.

( )

Grouping

Controls which conditions are evaluated together. tag:space (status:planning | status:in_progress)

,

AND list

Expands repeated qualifiers. tag:space,drama means tag:space tag:drama. Use | for OR.

Precedence

EZQ evaluates parentheses first, then negation, AND, and OR. Use parentheses when an expression mixes AND and OR. 

expression  = conjunction { "|" conjunction }
conjunction = factor { " " factor }
factor      = qualifier | bare-title | "!" factor | "(" expression ")"
qualifier   = field ":" value [ ":" option ]

Titles and spaces

Bare words are treated as a title. For example, /search spirited away becomes /search title:spirited_away.

In title and collection values, one underscore represents a space. Two underscores represent a literal underscore. collection:watch_later matches “watch later,” while collection:sci__fi matches “sci_fi.”

Fuzzy matching

Actions, qualifier names, and fixed values accept confident fuzzy matches. /s, type:movie, and status:progress are valid. The canonical form shown below the Query input is the exact form that Metavault will run.

Actions

Action Short form Syntax What it does
/search /s /search [filter] Returns matching entries. This is the default action.
/create /c /create values Creates an entry from a flat list of values.
/update /u /update filter > values Updates every entry matched by the left side.
/delete /d /delete filter Deletes every matching entry.

Search

If no action is present, EZQ uses /search. An empty search returns the whole library. Search is the only action that accepts sort.

/search status:planning sort:created_at:descending

Create

Create accepts a flat list of fields. A top-level OR creates one entry per branch. Shared fields outside a grouped OR are applied to every branch.

/create (title:bleach | title:dragon_ball_z) media_type:anime status:planning

Create cannot write id or use sort. Ratings and dates may omit the equality sign or use an explicit =, but cannot use inequalities.

Update

Update uses > to separate the filter from the new values. The separator needs a space on each side. The filter accepts the full expression syntax. The write side accepts values joined by AND, plus negated tags and collections. It does not accept OR.

/update status:planning > status:in_progress tag:started

Negate a tag or collection on the write side to remove it: !tag:drama or !collection:watch_later. Other fields cannot be removed with negation.

Delete

Delete accepts the same filters as search, except sort. Running a delete query opens a confirmation dialog with the current number of matching entries. Nothing is deleted until the query is confirmed. Commands are excluded from the count because they do not change the delete target.

/delete status:dropped created_at:<01-01-2025

Empty filters match the whole library. /update > status:planning updates every entry, and /delete targets every entry owned by the signed-in user. The delete confirmation count reflects that full target set.

Qualifiers

A qualifier has a field name and value separated by a colon: field:value. Some qualifiers accept a third segment.

Qualifier Value Example and notes
id Entry ID Exact match. May be used in filters, but not written.
title Text title:perfect_blue. Search matches the words in order.
tag value[:major|minor] tag:psychological:major. Weight defaults to major.
collection Collection name collection:weekend_list. Name matching ignores case.
status in_progress, dropped, planning, on_hold, finished status:in_progress
media_type movie, tv_show, anime, game, book, manga, other media_type:anime
public_rating Number from 0 to 10 public_rating:>=8. Comparators are allowed in filters.
personal_rating Number from 0 to 10 personal_rating:<6.5. Decimals are allowed.
adult true or false adult:false
created_at [comparator]dd-mm-yyyy created_at:>=01-01-2026
updated_at [comparator]dd-mm-yyyy updated_at:<15-06-2026
released_at [comparator]dd-mm-yyyy released_at:04-07-1999
sort field[:ascending|descending] sort:personal_rating:descending. Search only. Use it once, at the top level. Direction defaults to descending.

Comparators

Ratings and dates accept >, <, =, >=, and <=. Without a comparator, EZQ uses equality. Write values accept either no comparator or an explicit =; inequalities are only valid in filters.

Sortable fields

id title status media_type adult public_rating personal_rating released_at created_at updated_at

Commands

Commands start with #. EZQ removes them from the filter, runs the main action, then runs commands from left to right.

Commands do not narrow an update or delete. The action runs first, using only the expression. Commands then process the returned rows. Use aliases as search-result filters, not as selectors for write actions.

#enrich

#enrich[:mode][:source]

Enrichment fills entry metadata from a configured source. add is the default mode and fills missing fields. override replaces existing values. Supported sources are anilist, tmdb, igdb, and openlibrary.

The mode is positional. Use #enrich:add:tmdb or #enrich::tmdb to select TMDB; #enrich:tmdb is not valid. Search enrichment is temporary, create and update save enriched fields, and delete ignores enrichment.

/create title:akira media_type:anime status:planning #enrich:override:anilist

#pull

#pull:media_type:limit

Pull reads top unseen entries from the recommendation catalogue. The media type may be movie, tv_show, anime, game, book, manga, or all. The limit must be an integer from 1 to 500.

In search, pull replaces normal search results with catalogue previews. In create, it adds the pulled entries after any entries in the create expression. Update and delete ignore pull.

/search #pull:anime:20

#alias

#alias:name

Alias mappings are configured in Settings. Use 1 to 64 lowercase letters, numbers, underscores, or dashes for the name; command input is normalized to lowercase. The saved expansion is an EZQ filter and cannot contain another command. Alias matching filters rows returned by the action, so use it with search.

/search #alias:weekend

Unknown commands and commands with an unsupported argument shape are skipped without changing the result.

Common examples

High-rated unfinished anime

/search media_type:anime public_rating:>=8 !status:finished sort:public_rating:descending

Comedy movies or TV shows

/search tag:comedy (media_type:movie | media_type:tv_show)

Recently updated entries

/search updated_at:>=01-07-2026 sort:updated_at:descending

Create a book

/create title:the_left_hand_of_darkness media_type:book status:planning tag:science-fiction tag:classic:minor

Finish every entry in a collection

/update collection:summer_watchlist > status:finished

Move entries to another collection

/update collection:watch_next > !collection:watch_next collection:watched

Remove two tags

/update title:home_alone > !tag:holiday !tag:family

Create a movie and fetch its metadata

/create title:the_batman media_type:movie status:planning #enrich:override:tmdb

Add ten games from the catalogue

/create #pull:game:10
