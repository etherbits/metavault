Metavault is a self-hostable web application for tracking movies, TV shows, anime, games, books, manga, and other media in one place. The core library works without external services: users can create records, search them, organize them, and export their data. Source integrations and AI are opt-in. TMDB, AniList, IGDB, or OpenLibrary can fill metadata, and a local or hosted OpenAI-compatible model can power chat and recommendations.

Motivation and product scope

Purpose of Metavault

People who track several media types usually split their history across separate tools. Ratings, statuses, tags, unfinished items, and backups end up spread across different accounts.

Opt-in integrations

The library, EZQ, import/export, and account flows do not require metadata sources or an AI provider. Enrichment and assistant features are toggled on by users explicitly.

Data ownership

Library data lives in SQLite. It can be easily exported in bundles in a portable format, so it can be backed up, inspected, or moved.

Shared media model

Movies, shows, anime, games, books, and manga share one record shape for status, ratings, tags, and collections.

Easy enrichment

Configured source APIs can fill titles, covers, dates, public ratings, source IDs, and tags when the user asks for enrichment.

Portable setup

Docker and the open repository make the project easier to run, audit, modify, and reuse.

Features of Metavault

The current app supports the main flows: account creation and management, library management, querying and executing commands with EZQ, entry enrichment, chatting with assistants, getting recommendations, and importing/exporting.

EZQ (Easy Query)

EZQ is a Rust crate created by us. It gives us the ability to execute most common library management operations with easy syntax.

/s status:in_progress type:movieSearch in-progress movies

/c Dune type:book status:planningCreate an book entry

/u Joker > status:FinishedUpdate entry progress

/d public_rating:<7Delete entries

EZQ execution: The web client expands and validates commands for quick feedback using the EZQ crate built for browser environment. The server parses the same query again, builds the list of action, and runs them for the signed-in user using the EZQ crate built for Node.

Integrations, evidence, and next steps

Enrichment and recommendations

Source integrations can enrich saved entries and build the recommendation catalogue. Recommendation requests embed the prompt, filter catalogue candidates, and rank the matches before the assistant explains them.

Recommendation overview

MetaVault embeds the prompt and compares it with catalogue vectors using cosine similarity. The final score also considers keyword overlap, public rating, and popularity.

Future Improvements

Recommendation quality

Tune scoring weights, handle negative constraints better, and utilize a broader catalogue.

Usability improvements

Add release tracking, browser extensions for adding media easier, and a simpler way for less advanced users to query their libraries.

Query improvements

Improve EZQ docs and cross-media tag handling for movies, anime, games, books, manga, and shows.
