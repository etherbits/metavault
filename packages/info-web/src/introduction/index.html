Senior design project, Spring 2026

A self-hostable media library for records you actually want to keep.

MetaVault gives people one place to track movies, TV shows, anime, games, books, manga, and other media. The library works without external services: users can create records, search them, organize them, and export their data from a self-hosted app.

Purpose

One library for media history split across many tools.

People often keep films in Letterboxd, books in Goodreads, games in Backloggd, television in Trakt, and anime in AniList or MyAnimeList. That works until a user wants one searchable history with shared ratings, statuses, tags, and backups.

MetaVault focuses on the record around the media: what the user saved, finished, paused, dropped, tagged, rated, and wants to return to later. It is not a streaming platform or a playback server. It is a portable tracker for the history around those items.

Report #2 design rule The useful part of the product stays local.

Accounts, records, collections, EZQ, imports, and exports run without external services. Users can add metadata providers for enrichment, or connect a local or hosted model when they want assistant chat and recommendations.

How it works

Simple architecture, controlled execution.

The browser handles screens and fast feedback. The server handles auth, user-scoped records, EZQ execution, imports, recommendations, and SQLite writes.

Storage

SQLite

Entries, tags, collections, ratings, source metadata, and catalogue vectors.

EZQ trust boundary

The browser parses EZQ so the user gets quick feedback. The server parses it again, resolves the command, applies the signed-in user, and runs the database operation.

Recommendation pipeline

Source records become catalogue candidates. The service embeds the prompt, filters candidates, compares vectors with cosine similarity, and ranks the result set.

Self-hosted deployment

Docker and SQLite keep setup practical for technical users. The database is a file, and uploaded media stays with the server data.

Recommendation study

Early recommendation results passed the first targets.

Five participants evaluated 25 prompts. Each prompt returned five recommendations, for 125 item ratings. Scores of 3+ counted as useful, and scores of 4 or 5 counted as good.
